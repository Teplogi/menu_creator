# コラムの書き方

このフォルダに `.md` ファイルを1記事1つ置くと、アプリの「コラム」に出ます。
**ビルドは要りません。**保存して push すれば、そのまま本番に出ます。

## 書く・直す方法（3つ。どれでもOK）

**1. パソコンのエディタ**
リポジトリの `content/columns/` のファイルを VS Code やメモ帳で開いて編集 →
保存 → サーバを再起動すれば手元で確認できます。

**2. GitHub のサイト上（スマホからでも書けます）**
リポジトリ → `content` → `columns` → 記事を開いて鉛筆マーク → 直して Commit。
Render が自動で反映します（2〜3分）。新規記事は「Add file → Create new file」で
`ファイル名.md` を作るだけです。

**3. 書く前の下見**
手元で書いたときは、出す前に点検できます。

```bash
npm run columns
```

記事の一覧と、足りない項目があれば教えてくれます。ファイルは作られません。

## ファイルの形

ファイル名がそのままURLの一部（slug）になります。日本語ではなく英数字とハイフンで。
例: `warfarin-natto.md`

先頭の `---` ではさまれた部分に記事の情報を書きます。

```markdown
---
title: ワーファリンを飲んでいる方と、納豆・青汁
summary: 一覧に出る1〜2行の説明。何が分かる記事かを書く。
author: 新井 鉄平
author_title: 薬剤師
date: 2026-08-15
updated:
tags: [薬と食べ物, ワーファリン]
related_foods: [納豆, 青汁, クロレラ, ほうれん草, ブロッコリー]
hero: /columns/img/warfarin.png
draft: false
---

ここから本文。
```

| 項目 | 必須 | 説明 |
|---|---|---|
| `title` | ○ | 記事タイトル |
| `summary` | ○ | 一覧に出る説明。1〜2行 |
| `author` | ○ | 著者名。実名を推奨（信頼性と責任の所在のため） |
| `author_title` | | 肩書き（薬剤師 / 管理栄養士 など） |
| `supervisor` | | 監修者。名前ではなく **`supervisors.js` のキー**で書く（例: `dietitian`）。表示は「監修：管理栄養士 ひなた」のようになる。**その人が実際に記事を読んでチェックしたときだけ**付けること |
| `date` | ○ | 公開日 `YYYY-MM-DD` |
| `updated` | | 更新日。直したときに入れる |
| `tags` | | 分類用 |
| `related_foods` | | **この食材名が献立や買い物リストに出たとき、記事へ誘導します。**アプリで使う表記（にんじん・玉ねぎ など）で書く |
| `hero` | | 一覧に出すアイキャッチ画像 |
| `draft` | | `true` にすると出力されません（書きかけの記事） |

## 改行のしかた（ここだけ注意）

Markdown は「Enterを1回押しただけ」では改行になりません。読みやすいように
ファイルの中で折り返して書いても、表示ではひとつながりの文になります。

| やりたいこと | 書き方 |
|---|---|
| 段落を変える（あいだが少し空く） | **空行を1つ入れる** |
| 段落の中で改行する（詰めたまま） | **行末に半角スペースを2つ**打って改行 |
| 何もしない（折り返しただけ） | 続きの文としてつながります |

```markdown
これは1つ目の段落です。
ファイルの中で折り返して書いても、表示ではつながります。

ここから2つ目の段落。空行で区切りました。

朝食：トースト  
昼食：おにぎり  
夕食：焼き魚
```

最後の3行は「スペース2つ」で改行しているので、その通り3行で出ます。
（箇条書きにしたいときは `- ` を使ったほうが読みやすいです。）

## 本文で使える書き方

```markdown
## 見出し（## から。# は使わない＝タイトルと重複するため）
### 小見出し

ふつうの段落。**太字**、*斜体*、[リンク](https://example.com) が使えます。

- 箇条書き
- 箇条書き

1. 番号付き
2. 番号付き

> 引用にすると「注意ボックス」（色付きの枠）になります。
> 「必ず主治医・薬剤師にご相談ください」のような一文に使ってください。

![図の説明](/columns/img/vitamink.png)

---
```

## 画像（Canvaで作る図解・アイキャッチ）

`public/columns/img/` に置いて、本文からは `/columns/img/ファイル名.png` で参照します。

- 幅は **1200px程度** で書き出せば十分です（スマホでも綺麗に見えます）
- ファイルサイズは1枚 200KB 以内を目安に（PNGよりJPGのほうが軽くなることが多いです）
- **文字だけの画像は作らないでください。**検索に引っかからず、食材からも引けなくなります。図解に徹してください

## 決まりごと

- 記事の末尾には、**免責と著者名が自動で入ります**（自分で書かなくてOK）
- 一般的な情報提供にとどめ、特定の方への指導はしないでください
- 「この薬を飲んでいる人は絶対に食べるな」のような断定は避け、
  「主治医・薬剤師にご相談ください」に着地させてください

## 栄養コメントから記事へ飛ばす

`advice_tags` を書いておくと、栄養画面の「塩分が多めです」などのコメントから
その記事へのリンクが出ます。「多いですよ」で終わらせず、対策まで読めるようにするためです。

```markdown
advice_tags: [salt, soup]
```

使えるタグ: `salt`（塩分が多い）/ `soup`（汁物が続く）/ `fiber`（野菜が少ない）/
`protein`（たんぱく質が少ない）/ `fat`（脂質が多い）/ `kcal`（カロリー）

## 表

Markdownの表が使えます。

```markdown
| 食品 | 食塩相当量 |
|---|---|
| ちくわ 1本 | 約0.6g |
| 梅干し 1個 | 約2.0g |
```

いちばん右の列は右寄せになります（数値を並べる想定）。狭い画面では表だけ横スクロールします。
